# Initial related-work reading list

This is a starting list, not a completed systematic review. Verify metadata and read full papers before making novelty claims.

- SparseInfer, ICML 2026: https://proceedings.mlr.press/v306/wang26hn.html
- SEAP, AAAI 2026: https://doi.org/10.1609/aaai.v40i38.40463
- Attribution-based Sparse Activation, MLSys 2026: https://proceedings.mlsys.org/paper_files/paper/2026/hash/29591f355702c3f4436991335784b503-Abstract-Conference.html
- DynamicInfer, ICLR 2026: https://proceedings.iclr.cc/paper_files/paper/2026/hash/0b9762d1f15c68057275fa18d384c1a8-Abstract-Conference.html
- Balcony, EMNLP 2025: https://aclanthology.org/2025.emnlp-main.1263/
- Adaptive Computation Modules, AAAI 2025: https://doi.org/10.1609/aaai.v39i20.35453
- Router-R1, NeurIPS 2025: https://proceedings.neurips.cc/paper_files/paper/2025/hash/ceaa137fce916aba5c65fceb1309088b-Abstract-Conference.html
- Switchcraft: https://www.microsoft.com/en-us/research/publication/switchcraft-ai-model-router-for-agentic-tool-calling/
- Select-then-Route, EMNLP Industry 2025: https://aclanthology.org/2025.emnlp-industry.28/

For each work, record task, architecture, routed component, static/contextual/sequential selection, training signal, quality constraint, end-to-end overhead, hardware, repeated-workload evaluation, limitations, and overlap with WSP. Routing, sparse activation, conditional computation, and RL selection are not novel in isolation.
